# dsh://terminal

 

一个零依赖的单页站点, 把"终端"当作界面语言:

- background ...... canvas 实时绘制的几何图形

- navigation ...... hash 路由, 无刷新 平滑过渡

- motion ......... DOM smear / 运动模糊拖影

- palette ........ black · white · red · green · blue

 

$

核心特性

四件事:几何、动效、无刷新与克制。

01 / CANVAS

几何动态背景

透视网格、漂浮线框多边形与星座连线, 全部由 Canvas 实时绘制, 图形数量随视口自适应。

02 / SMEAR

运动模糊拖影

导航展开时, 每个链接都会拖出一串沿轨迹滞后、逐渐变淡变模糊的残影, 并用屏幕混合叠加出发光感。

03 / ROUTER

无刷新页面切换

hash 路由 + 片段预取: 旧内容模糊上移淡出, 新内容模糊上移淡入, 全程没有一次整页加载。

04 / A11Y

可访问与可降级

完整键盘导航、焦点样式与 ARIA 标注; 开启"减少动态效果"后自动关闭拖影与背景动画。
