工具页面

下面是几个直接跑在浏览器里的迷你工具。终端支持历史记录(↑/↓)、Tab 补全与内置虚拟文件系统。

guest@dsh: ~/tools 交互终端
guest@dsh:~/tools$

工具清单

全部在前端完成, 不会把数据发到任何服务器。

01

Base64 编解码

b64 / b64d 两个命令, 支持 UTF-8 文本的往返转换。

b64b64d
02

UUID v4 生成

优先使用 crypto.randomUUID, 不支持时回退到 getRandomValues。

uuid 5
03

JSON 格式化

把压缩的一行 JSON 展开成缩进结构, 并给出解析错误位置。

json
04

SHA-256 摘要

基于 WebCrypto 的摘要计算, 需要 https 或 localhost 环境。

sha256
05

主题强调色

accent red | green | blue 实时切换整站强调色, 并记忆到本地。

accent
06

页面跳转

在终端里直接输入 open contact 之类的命令即可切换页面。

open
note.txt

$ cat note.txt

提示: 终端是纯前端的演示实现, 命令与输出都在本地生成。按 Ctrl+L 可以清屏。
