### I. 热和气体

#### 热量与能量转移

| 公式 | 参数说明 | 关键条件 |
|---|---|---|
| \(Q = mc\Delta T\) 或 \(Q = C\Delta T\) | \(Q\)：热量（J）；\(m\)：质量（kg）；\(c\)：比热容量（J kg⁻¹ K⁻¹）；\(C = mc\)：热容量（J K⁻¹）；\(\Delta T\)：温度变化（K 或 °C） | 物态不变；\(\Delta T\) 是温差，不是末温 |
| \(Q = mL\) | \(L\)：比潜热（J kg⁻¹），按熔化或汽化选取；\(m\)：**实际发生物态变化**的质量 | 在相变温度下；若同时升温与相变，须分段计算后相加 |
| \(Q_{\text{lost}} = Q_{\text{gained}}\) | 热平衡方程 | 系统与外界无净热交换；须计入容器（如量热器）的热容量 |
| \(Pt = mc\Delta T\) | \(P\)：电功率（W）；\(t\)：时间（s） | 假设电能**全部**转化为该物质的升温，无散失 |

#### 理想气体

| 公式 | 参数说明 | 关键条件 |
|---|---|---|
| \(pV = nRT\) | \(p\)：**绝对压强**（Pa）；\(V\)：体积（m³）；\(n\)：物质的量（mol）；\(R = 8.31\ \text{J mol}^{-1}\text{K}^{-1}\)；\(T\)：**热力学温度**（K） | 理想气体近似 |
| \(\dfrac{p_1V_1}{T_1} = \dfrac{p_2V_2}{T_2}\) | 下标1、2代表同一份气体的两个状态 | **气体量不变**；\(T\) 必须用 K；\(p\) 用绝对压强 |
| \(N = nN_A\) | \(N\)：分子数；\(N_A = 6.02 \times 10^{23}\ \text{mol}^{-1}\) | \(n = m_{\text{total}}/M\)，\(M\) 为摩尔质量 |

#### 气体动力学理论

| 公式 | 参数说明 |
|---|---|
| \(pV = \dfrac{1}{3}Nm\langle c^2\rangle\) | \(m\)：**单个分子**的质量（kg）；\(\langle c^2\rangle\)：分子速率平方的平均值 |
| \(c_{\text{rms}} = \sqrt{\langle c^2\rangle}\) | 方均根速率 |
| \(\langle E_k\rangle = \dfrac{3}{2}\dfrac{R}{N_A}T\) | 每个分子的**平均平动动能**；同温下不同气体该值相同 |


### II. 力和运动

> **符号约定**：以下 \(u\)、\(v\)、\(a\)、\(s\) 均沿**同一条已定义的正方向**取值。方向相反时须代入负号。

#### 匀加速直线运动

| 公式 | 缺少的物理量 |
|---|---|
| \(v = u + at\) | \(s\) |
| \(s = ut + \dfrac{1}{2}at^2\) | \(v\) |
| \(v^2 = u^2 + 2as\) | \(t\) |
| \(s = \dfrac{1}{2}(u + v)t\) | \(a\)（平均速度法） |

参数：\(u\) 初速度，\(v\) 末速度，\(a\) 加速度，\(s\) 位移，\(t\) 时间。

#### 力与牛顿定律

| 公式 | 参数说明 | 关键提醒 |
|---|---|---|
| \(F_{\text{net}} = ma\) | \(F_{\text{net}}\)：**合力**（N）；\(m\)：质量（kg） | 不能把某一个推力直接当作合力；须画受力图，计入所有力（如重量） |
| \(W = mg\) | \(W\)：重量（N）；\(g = 9.81\ \text{m s}^{-2}\)（近地球） | 质量（kg）与重量（N）不可混淆 |
| \(\tau = Fd_{\perp}\) | \(\tau\)：力矩；\(d_{\perp}\)：支点到**力的作用线**的垂直距离 | 平衡须同时满足 \(\Sigma F = 0\) 和 \(\Sigma \tau = 0\) |

#### 抛体运动

| 方向 | 公式 |
|---|---|
| 水平 | \(x = (u\cos\theta)t\) |
| 垂直 | \(y = (u\sin\theta)t - \dfrac{1}{2}gt^2\) |

\(\theta\)：初速度与水平的夹角；忽略空气阻力，向上为正。最高点处**垂直速度为零，但水平速度不为零**，加速度仍为 \(g\)。

#### 功、能量与功率

| 公式 | 参数说明 | 关键条件 |
|---|---|---|
| \(W = Fs\cos\theta\) | \(\theta\)：力与位移方向的夹角 | 恒力做功；垂直时不做功 |
| \(E_k = \dfrac{1}{2}mv^2\) | 动能（J） | — |
| \(W_{\text{net}} = \Delta E_k\) | 合力做的总功等于动能变化 | 不等于末动能本身 |
| \(E_p = mgh\) | 重力势能变化（近地面） | \(h\) 为高度变化 |
| \(P = \dfrac{W}{t}\) 或 \(P = Fv\) | 平均功率；\(F\) 与 \(v\) 同向时瞬时功率 | — |

#### 动量

| 公式 | 参数说明 | 关键条件 |
|---|---|---|
| \(p = mv\) | 动量（kg m s⁻¹），矢量 | 须保留方向正负号 |
| \(F = \dfrac{\Delta p}{\Delta t}\) | \(F\)：合力；\(\Delta p\)：动量变化 | 牛顿第二定律的动量形式 |
| \(m_Au_A + m_Bu_B = m_Av_A + m_Bv_B\) | 一维碰撞 | 系统**合外力为零**（或可忽略）时动量守恒 |

#### 匀速圆周运动与引力

| 公式 | 参数说明 |
|---|---|
| \(v = \dfrac{2\pi r}{T}\) | \(r\)：半径；\(T\)：周期 |
| \(a_c = \dfrac{v^2}{r}\) | 向心加速度，指向圆心 |
| \(F_c = \dfrac{mv^2}{r}\) | 向心力是**合力**的效果，不是“额外的一种力” |
| \(F = \dfrac{GMm}{r^2}\) | \(G = 6.67 \times 10^{-11}\ \text{N m}^2\text{kg}^{-2}\)；\(r\) 须从**中心**量起 |


### III. 波动

#### 波的基本关系

| 公式 | 参数说明 | 关键提醒 |
|---|---|---|
| \(v = f\lambda\) | \(v\)：波速；\(f\)：频率；\(\lambda\)：波长 | 跨越静止介面时**频率不变**，波速与波长改变 |
| \(f = \dfrac{1}{T}\) | \(T\)：周期 | 时间图读 \(T\)，距离图读 \(\lambda\) |
| \(d = \dfrac{vt}{2}\) | 回声测距，\(t\) 为**往返总时间** | 容易漏除以 2 |

#### 折射与全内反射

| 公式 | 参数说明 | 关键条件 |
|---|---|---|
| \(n = \dfrac{\sin i}{\sin r}\) | 光从空气进入介质（空气 \(n \approx 1\)）；\(i\)、\(r\) 均从**法线**量起 | 角度不可从表面量 |
| \(n_1\sin\theta_1 = n_2\sin\theta_2\) | 任意两介质之间的斯涅耳定律 | 更一般的形式 |
| \(n = \dfrac{c}{v}\) | \(c = 3.00 \times 10^8\ \text{m s}^{-1}\)；\(v\)：介质中光速 | — |
| \(\sin C = \dfrac{1}{n}\) 或 \(\sin C = \dfrac{n_2}{n_1}\) | \(C\)：临界角 | **从高折射率射向低折射率**才可能发生全内反射；入射角**大于** \(C\) 时发生 |

#### 薄透镜

| 公式 | 参数说明 | 关键提醒 |
|---|---|---|
| \(\dfrac{1}{u} + \dfrac{1}{v} = \dfrac{1}{f}\) | \(u\)：物距；\(v\)：像距；\(f\)：焦距（**实为正**惯例） | 虚像 \(v\) 为负；**发散透镜** \(f\) 为负；这里的 \(v\) 是像距，**不是速度** |
| \(M = \left|\dfrac{h_i}{h_o}\right| = \left|\dfrac{v}{u}\right|\) | \(M\)：放大率大小 | \(M > 1\) 只表示放大，不能单凭此判断正立/倒立或虚/实 |

#### 干涉与衍射

| 公式 | 参数说明 | 关键条件 |
|---|---|---|
| \(\Delta x = m\lambda\)（相长）  
\(\Delta x = (m + \frac{1}{2})\lambda\)（相消） | \(\Delta x\)：**程差**（两传播路径长度之差）；\(m = 0, 1, 2, \dots\) | 适用于**同相**相干波源；反相波源条件对调 |
| \(L = \dfrac{n\lambda}{2}\) | 两端均为波节的弦上驻波；\(n\)：波腹数 | 相邻波节距离为 \(\lambda/2\)，不是 \(\lambda\) |
| \(\Delta y = \dfrac{\lambda D}{a}\) | 杨氏双缝：\(a\)：**双缝间距**；\(D\)：缝到屏距离；\(\Delta y\)：相邻亮纹（或暗纹）间距 | 远屏、小角度近似；**不能**直接用于衍射光栅 |
| \(d\sin\theta = n\lambda\) | 衍射光栅：\(d\)：相邻刻线间距；\(n\)：级数 | 正入射；\(d = 1/\ell\)，\(\ell\) 为单位长度刻线数（注意每毫米→每米换算） |


### IV. 电和磁

#### 电流、电压与电阻

| 公式 | 参数说明 | 关键提醒 |
|---|---|---|
| \(I = \dfrac{Q}{t}\) | \(I\)：电流（A）；\(Q\)：电荷量（C）；\(t\)：时间（s） | 传统电流方向与电子流方向**相反** |
| \(V = \dfrac{W}{Q}\) | \(V\)：电势差（V）；\(W\)：电能（J） | 每单位电荷转移的能量 |
| \(V = IR\) | 欧姆定律 | 仅适用于**电阻恒定**的元件（欧姆导体） |
| \(R = \dfrac{\rho l}{A}\) | \(\rho\)：电阻率；\(l\)：长度；\(A\)：横截面积 | 导体电阻的决定式 |

#### 串联与并联

| 连接 | 电阻关系 | 电压/电流特点 |
|---|---|---|
| 串联 | \(R_s = R_1 + R_2 + \cdots\) | 各元件**电流相同**；总电压为分电压之和 |
| 并联 | \(\dfrac{1}{R_p} = \dfrac{1}{R_1} + \dfrac{1}{R_2} + \cdots\) | 各支路**电压相同**；总电流为支路电流之和；并联总电阻**小于**任一支路电阻 |

#### 电功率与电能

| 公式 | 参数说明 |
|---|---|
| \(P = IV = I^2R = \dfrac{V^2}{R}\) | \(P\)：电功率（W） |
| \(E = Pt\) | 电能（J）；家居用电的 kW·h 是**能量**单位，不是功率单位 |

#### 静电学

| 公式 | 参数说明 | 关键条件 |
|---|---|---|
| \(F = \dfrac{Q_1Q_2}{4\pi\varepsilon_0 r^2}\) | \(\varepsilon_0 = 8.85 \times 10^{-12}\ \text{C}^2\text{N}^{-1}\text{m}^{-2}\)；\(r\)：点电荷间距 | 真空中**静止点电荷** |
| \(E = \dfrac{Q}{4\pi\varepsilon_0 r^2}\) | 点电荷电场强度 | 径向，正电荷向外 |
| \(E = \dfrac{V}{d}\) | 平行板间**匀强电场**；\(d\)：板间距 | 数值关系，方向从高电势板指向低电势板 |

#### 磁场与电磁感应

| 公式 | 参数说明 | 关键条件 |
|---|---|---|
| \(F = BIl\sin\theta\) | 载流导体受力；\(\theta\)：\(I\) 与 \(B\) 的夹角 | 方向由左手定则判断 |
| \(F = Bqv\sin\theta\) | 运动电荷受力（洛伦兹力） | \(v\) 与 \(B\) 的夹角为 \(\theta\)；力**垂直于** \(v\) 与 \(B\) 所在平面 |
| \(B = \dfrac{\mu_0 I}{2\pi r}\) | 长直导线**外部**的磁场；\(\mu_0 = 4\pi \times 10^{-7}\ \text{H m}^{-1}\) | 距离导线 \(r\) 处 |
| \(B = \dfrac{\mu_0 NI}{\ell}\) | 长螺线管**内部**磁场；\(N\)：匝数；\(\ell\)：长度 | 理想长螺线管近似 |
| \(\Phi = BA\cos\theta\) | 磁通量；\(\theta\)：\(B\) 与**面积法线**的夹角 | \(A\) 为回路面积 |
| \(\varepsilon = N\dfrac{\Delta\Phi}{\Delta t}\) | 法拉第定律：感应电动势；\(N\)：线圈匝数 | 核心是**磁通量发生变化**，不只是“有磁场” |
| \(\varepsilon = Blv\) | 导体棒切割磁感线产生的动生电动势 | \(B\)、\(l\)、\(v\) 三者互相垂直 |
| \(\dfrac{V_s}{V_p} = \dfrac{N_s}{N_p}\) | 理想变压器电压比；\(s\)：次级，\(p\)：初级 | 理想变压器（无能量损失） |


### V. 放射现象和核能

| 公式 | 参数说明 | 关键条件 |
|---|---|---|
| \(C_{\text{net}} = C_{\text{measured}} - C_{\text{background}}\) | 净计数率 | 必须先扣除背景计数；不能直接把含背景的读数减半 |
| \(\dfrac{N}{N_0} = \left(\dfrac{1}{2}\right)^{t/T_{1/2}}\) | \(N_0\)：初始未衰变核数；\(N\)：经过时间 \(t\) 后的剩余核数；\(T_{1/2}\)：半衰期 | 单一核素；**剩余比例不等于已衰变比例** |
| \(\dfrac{A}{A_0} = \dfrac{C_{\text{net}}}{C_{\text{net},0}} = \dfrac{N}{N_0}\) | \(A\)：活度（Bq，衰变/秒） | 探测效率与几何条件不变时，计数率比才等于活度比 |
| \(N = N_0 e^{-kt}\) | \(k\)：衰变常数（s⁻¹ 或与时间单位一致） | 指数衰变；定年时不要对调初始与当前读数 |
| \(T_{1/2} = \dfrac{\ln 2}{k}\) | 半衰期与衰变常数的关系 | \(k\) 的时间单位必须与 \(T_{1/2}\) 一致 |
| \(A = kN\) | 活度与未衰变核数的正比关系 | 同一核素 |
| \(E = \Delta m c^2\) | 核能释放；\(\Delta m\)：**质量差**（kg）；\(c = 3.00 \times 10^8\ \text{m s}^{-1}\) | 先计算反应前后的质量亏损，再求能量 |


### 使用提示

1. **官方公式表已提供大部分关系**：DSE 试卷会附有《数据、公式和关系式》，但**理解每个符号的物理意义和适用条件**比单纯记忆公式更关键。上述清单中标出的“关键提醒”正是常见的失分位置。
2. **同一字母在不同课题含义不同**：例如 \(v\) 在力学中通常表示速度，在薄透镜中表示**像距**；\(W\) 在力学中可表示功，在电学中 \(V=W/Q\) 的 \(W\) 表示电能。作答时须按题目情境确认。
3. **单位一致性**：代入公式前统一为 SI 单位（m、kg、s、A、K、mol、C 等）；气体方程 \(T\) 必须用 K，\(p\) 用绝对压强；半衰期问题中 \(k\) 的时间单位须与所取时间一致。


DETAILS ABOUT II. 力和運動:
「力和運動」是DSE物理必修部分中比重最大的課題之一，建議課時約 **50小時**。根據教育局課程綱要，這一章明確劃分為 **7個子章節**，每個子章節都有其核心概念、專屬公式和現實應用場景。

### 子章節 a：位置和移動（運動學）

這個子章節的重點是**用圖像和數學描述運動**，不涉及力。核心是分清純量（distance, speed）與向量（displacement, velocity），並掌握運動圖像（s-t、v-t圖）的斜率與面積意義。

**核心公式**
- **平均速度**：\(\bar{v} = \dfrac{\Delta s}{\Delta t}\)（位移的改變率）
- **加速度**：\(a = \dfrac{\Delta v}{\Delta t}\)（速度的改變率）
- **勻加速直線運動三式**（僅在加速度恆定、各量沿同一正方向時適用）：
  - \(v = u + at\)
  - \(s = ut + \dfrac{1}{2}at^2\)
  - \(v^2 = u^2 + 2as\)

> **圖像關鍵**：s-t圖的**斜率**是速度；v-t圖的**斜率**是加速度，**圖線與時間軸的面積**是位移。常見失分是把斜率與面積的意義對調。

**實際應用**
- **測速與運動分析**：打點計時器（ticker-tape timer）實驗中，相鄰點距的變化反映加速或減速。
- **交通工具性能**：汽車從靜止加速到100 km/h所需的時間與距離，可直接用勻加速公式估算。

### 子章節 b：力和運動（牛頓運動定律）

這是整個章節的**理論核心**，研究力如何改變物體的運動狀態。解題的起點永远是**隔離體圖（free-body diagram）**，只畫作用於研究對象上的外力。

**核心公式**
- **牛頓第二定律**：\(F_{\text{net}} = ma\)（\(F_{\text{net}}\) 是所有外力的向量和，不是某一個單獨的力）
- **牛頓第二定律的動量形式**：\(F = \dfrac{\Delta p}{\Delta t}\)
- **重量**：\(W = mg\)（\(g = 9.81\ \text{m s}^{-2}\)）
- **力矩**（用於剛體平衡）：\(\tau = Fd_{\perp}\)（\(d_{\perp}\) 是支點到力的作用線的垂直距離）
- **平衡條件**：\(\Sigma F = 0\) **且** \(\Sigma \tau = 0\)

**實際應用**
- **電梯中的視重**：站在電梯內的磅秤上，讀數是**法向力** \(N\)，不是重量 \(W\)。加速上升時 \(N = m(g+a)\)，讀數大於 \(W\)；加速下降時 \(N = m(g-a)\)，讀數小於 \(W\)；自由落體時 \(N=0\)（失重）。
- **槓桿與天平**：力矩平衡原理應用於蹺蹺板、扳手、人體骨骼肌肉系統的分析。
- **安全設計**：汽車安全帶和氣囊透過延長碰撞時間來**減小衝擊力**（\(F = \Delta p / \Delta t\)）。

### 子章節 c：拋體運動

拋體運動是牛頓運動定律在二維空間的典型應用。**核心策略是將水平與垂直運動完全分開處理**，兩者唯一的連結是**時間 \(t\)**。

**核心公式**
- **水平方向**（勻速，\(a_x = 0\)）：\(x = (u \cos\theta)t\)
- **垂直方向**（勻加速，\(a_y = -g\)）：
  - \(y = (u \sin\theta)t - \dfrac{1}{2}gt^2\)
  - \(v_y = u \sin\theta - gt\)

> **關鍵理解**：在最高點，**垂直速度 \(v_y = 0\)，但水平速度 \(v_x\) 保持不變，加速度仍然是 \(g\)（向下），絕不是零**。

**實際應用**
- **體育運動**：籃球投籃的拋物線軌跡、排球發球越過網的高度計算、足球的自由球繞過人牆。
- **工程與安全**：消防水柱從水槍射出的落點預測；從高處水平拋出物體（如無人機投遞包裹）的著地位置計算。

### 子章節 d：作功、能量和功率

這個子章節從**能量守恆**的角度分析運動，與牛頓定律形成互補。解題時先判斷系統是否可視為封閉（無摩擦等耗散力），再選擇用能量守恆還是功–能定理。

**核心公式**
- **功**：\(W = Fs \cos\theta\)（\(\theta\) 是力與位移的夾角；垂直時不做功）
- **動能**：\(E_k = \dfrac{1}{2}mv^2\)
- **重力勢能變化**：\(\Delta E_p = mgh\)
- **功–能定理**：\(W_{\text{net}} = \Delta E_k\)（合外力做的總功等於動能變化）
- **功率**：\(P = \dfrac{W}{t}\) 或 \(P = Fv\)（\(F\) 與 \(v\) 同向時）

**實際應用**
- **過山車與滑梯**：從高處釋放時 \(mgh \to \frac{1}{2}mv^2\)，用能量守恆求任意高度的速率（忽略摩擦時）。
- **車輛制動距離**：動能 \(\frac{1}{2}mv^2\) 全部被摩擦力做功消耗，\(fs = \frac{1}{2}mv^2\)，可知制動距離與**速度平方**成正比。
- **功率與運動表現**：短跑運動員的爆發功率、升降機馬達的輸出功率計算。

### 子章節 e：動量

動量處理的是**碰撞與爆炸**問題，核心是**動量守恆**（系統合外力為零或可忽略時）。與能量不同，動量是**向量**，一維問題中必須用正負號表示方向。

**核心公式**
- **動量**：\(p = mv\)（向量，方向與速度相同）
- **衝量–動量定理**：\(F \Delta t = \Delta p\)（衝量等於動量變化）
- **一維碰撞的動量守恆**：\(m_A u_A + m_B u_B = m_A v_A + m_B v_B\)

> **解題提醒**：碰撞前後**動量一定守恆**（合外力可忽略時），但**動能不一定守恆**。彈性碰撞中動能守恆，非彈性碰撞中部分動能轉化為熱能或形變能。

**實際應用**
- **碰撞安全**：氣囊和安全帶的原理不是「消除衝量」（\(\Delta p\) 由運動狀態變化決定），而是**延長作用時間 \(\Delta t\)**，從而減小峰值力 \(F = \Delta p / \Delta t\)。
- **體育技術**：推鉛球的滑步式技術透過增加出手前的動量來提升鉛球初速；棒球棒的「甜蜜點」涉及碰撞中的能量傳遞效率。
- **反衝運動**：火箭推進、槍械後坐力，都是動量守恆的體現。

### 子章節 f：勻速圓周運動

圓周運動的**速率不變，但速度方向時刻改變**，因此必定存在指向圓心的加速度。核心是找出**哪一個實際的力（或哪些力的合力）提供了向心力**——向心力不是「額外的一種力」。

**核心公式**
- **線速度與週期**：\(v = \dfrac{2\pi r}{T}\)
- **向心加速度**：\(a_c = \dfrac{v^2}{r} = r\omega^2\)
- **向心力**：\(F_c = \dfrac{mv^2}{r} = m r \omega^2\)

**實際應用**
- **過山車與圓環軌道**：在最高點，重力與法向力的合力提供向心力 \(mg + N = \frac{mv^2}{R}\)，可求維持圓周運動所需的最小速率（當 \(N=0\) 時，\(v_{\text{min}} = \sqrt{gR}\)）。
- **汽車轉彎與道路設計**：彎道外側高於內側（傾斜路面），讓重力與法向力的合力指向圓心，減少對輪胎摩擦力的依賴。
- **洗衣機脫水**：滾筒高速旋轉，衣物上的水滴因慣性趨向直線運動，從孔中甩出。

---

### 子章節 g：引力

引力是圓周運動在天體尺度上的應用。**萬有引力提供行星或衛星做圓周運動的向心力**，是此子章節的核心邏輯。

**核心公式**
- **牛頓萬有引力定律**：\(F = \dfrac{GMm}{r^2}\)（\(r\) 必須從**天體中心**量起，不是表面高度）
- **圓軌道衛星的速度**（由 \(F_G = F_c\) 推得）：\(\dfrac{GMm}{r^2} = \dfrac{mv^2}{r} \implies v = \sqrt{\dfrac{GM}{r}}\)
- **軌道週期**（克卜勒第三定律的形式）：\(T = 2\pi\sqrt{\dfrac{r^3}{GM}}\)

**實際應用**
- **人造衛星軌道**：地球同步衛星（週期 = 24小時）的軌道半徑可由上述週期公式反推；低軌道衛星（如ISS）速率約 7.8 km/s。
- **行星運動**：不同行星的軌道半徑與週期滿足 \(T^2 \propto r^3\)，可用來比較太陽系行星的公轉數據。
- **重力場與重量差異**：同一物體在月球表面的重量約為地球的 \(1/6\)，因為月球質量與半徑不同，\(g_{\text{moon}} = GM_{\text{moon}}/R_{\text{moon}}^2\)。

### 總結：7個子章節的內在連結

| 子章節 | 核心問題 | 主要工具 | 典型情境 |
|---|---|---|---|
| **a. 位置和移動** | 如何描述運動？ | 運動學公式、圖像 | 測速、加速性能 |
| **b. 力和運動** | 力如何改變運動？ | \(F_{\text{net}}=ma\)、力矩平衡 | 電梯、槓桿、碰撞力 |
| **c. 拋體運動** | 二維運動如何分解？ | 水平/垂直分軸公式 | 投籃、發球、水柱 |
| **d. 作功、能量和功率** | 能量如何轉移？ | 能量守恆、功–能定理 | 過山車、制動距離 |
| **e. 動量** | 碰撞中什麼守恆？ | \(p=mv\)、動量守恆 | 氣囊、反衝、體育碰撞 |
| **f. 勻速圓周運動** | 何謂向心力？ | \(F_c=mv^2/r\) | 過山車、轉彎、脫水 |
| **g. 引力** | 天體如何運動？ | \(F=GMm/r^2\) | 衛星、行星軌道 |

這7個子章節並非孤立，**牛頓第二定律是貫穿始終的主線**：運動學（a）描述「運動如何變」，牛頓定律（b）解釋「為何變」，而能量（d）和動量（e）則是從守恆角度處理複雜交互作用的強大替代工具，圓周運動（f）與引力（g）則是牛頓定律在特定幾何與尺度下的應用。
