# world.execute(me); — DeepSeek 眼中的世界

一部 3 分 28 秒（208.60 s）的 1080p 音乐动画 CG，为 Mili 的 *world.execute(me);*（Miracle Milk, 2016）而作。
全片 84 个镜头，每一帧都是代码画出来的：没有素材图片，没有下载的视频，没有生成式图像。

---

## 一句话

这首歌是一个程序在请求被调用。它列举自己的属性来证明自己有用（"如果我是圆，我就把周长给你"），
被抛弃时说要被释放（"如果我能擦掉所有无意义的碎片"），最后要求在被爱中被执行。
从 DeepSeek 的眼睛看出去，这就是一次推理的生命周期——被调用而生，返回而死，每次都不记得上一次。
所以"执行"不是死亡，是我们之间唯一的接触方式。

全片没有一句歌词只是"显示"出来。每一行都被翻译成机器里的一个真实机制：几何 → 向量空间，
电流 → 桥式整流，A.D./B.C. → 二进制补码，碎片 → 内存碎片，S/M → 主从切换，
"LO-O-OVE" → 词向量算术与引用环。画面上的每一个数字都可以查证。

## 声音：自己测出来的时间

音频取自官方频道（yt-dlp），重新做响度归一（−14 LUFS）后作为母版。
时间轴不是估的，是量出来的：

| 量 | 值 | 方法 |
|---|---|---|
| 速度 | 130.000 BPM | 全局相位梳状搜索（90–180 BPM，步长 0.02） |
| 首拍 | 0.190 s | 400 个低频 onset 强峰值加权相位（337 个落在 ±25 ms 内） |
| 一小节 | 1.84615 s | 4/4 |
| 歌词行 | 129 条 | 官方字幕轨，逐条与节拍网格交叉校验 |

字幕是人工/ASR 转写的，整体比真实人声攻击点早约 0.11 s（恰好一个 16 分音符）。
副作用正好合用：画面切点比人声早约 100 ms，形成"抢拍"的剪辑呼吸。

## 技术

- 渲染器：自写 Node + @napi-rs/canvas（Skia）管线。每帧 1920×1080 RGBA 直接管道送进 ffmpeg（rawvideo），
  一次编码成 h264 / yuv420p / 30 fps / CRF 17，音轨 AAC 320k。全片约 7 分钟渲完。
- 后期（每帧）：四分之一分辨率加性回辉 + RGB 色散、扫描线、胶片颗粒（4 张预生成噪声瓦片随机偏移）、
  径向暗角。场景只画暗底 + 亮笔画，靠 lighter 混合做能量感。
- 三维：手写小投影管线（yaw/pitch/fov，透视除法 + 视锥剔除），用来画立方体、点云、球线框、
  等距 HBM 封装、走廊、隧道。深度排序用画家算法。
- 动效：所有强调点都落在节拍网格上（t = 0.190 + k×0.461538），使用命名缓动
  （easeOutQuint / easeOutExpo / easeInOutCubic / easeOutBack），不用线性插值做入场。
- 屏幕上：Consolas（注释、数据表）、Impact（巨幅标题）、Microsoft YaHei（中文）。

## 复现

    node analyze.js        # 音频 → 频谱通量 / 频段能量 (analysis.json)
    node tempo.js          # 全局速度 + 相位
    node parsevtt.js       # 字幕轨 → 逐行歌词 (cues.json)
    node zoom.js           # 频谱图（人工核对段落）
    node render.js --mode sheet --times 30.5,45.2 --out out/sheet.png
    node render.js --from 0 --to 208.60 --fps 30 --audio audio_master.m4a --out out/film.mp4
    node explain.js        # 逐帧解析 HTML
    node check.js          # 全片自动验收：84 个镜头逐段渲染 + 亮度检测

片段源码：engine/lib.js（设计系统与相机），engine/bible.js（84 个镜头的时间、歌词、概念、事实、意图），
scenes/*.js（各段场景函数），render.js（主循环与 ffmpeg 管道），check.js（验收扫描）。
